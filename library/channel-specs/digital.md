# Digital and landing specs

## Display
- Common sizes: 300x250, 728x90, 160x600, 320x50, 970x250.
- Keep copy minimal; logo and CTA legible at small sizes.
- Provide HTML5 or static files per the media plan.

## Landing page
- One conversion goal per page.
- Above the fold: proposition, proof, CTA.
- Mobile-first; fast load; accessible contrast and focus states.
- Copy hierarchy: headline, subhead, proof, CTA, FAQ.

## Website banners
- Match the page context; do not cover navigation or legal text.
- Provide desktop and mobile crops.

## Best practices
- Verify ad platform policies and file limits.
- Track UTM parameters with the media team.
- Test the page on mobile before approval.
